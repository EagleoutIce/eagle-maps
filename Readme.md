# eagle-maps.sty

This LaTeX2e-Package allows the simple creation of maps using TikZ. It offers coordinate-generation, player-handling, tile-control and much more.

Please consult the [documentation](https://raw.githubusercontent.com/EagleoutIce/eagle-maps/gh-pages/eagle-maps.pdf) for any details or examples.

The documentation is built against [xlistings](https://github.com/EagleoutIce/xlistings), which is vendored as a git submodule in `lib/xlistings`. Clone with `--recurse-submodules` (or run `git submodule update --init`) before compiling `eagle-maps.tex`.
